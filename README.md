# CGPA Calculator - CodeAlpha Internship Task 1

A simple C++ console program to calculate semester GPA and cumulative CGPA.

### Features
* Calculates GPA for multiple semesters
* Calculates the overall CGPA based on credit hours and grade points
* Validates inputs (grade points between 0.0-4.0, credit hours between 1-6)
* Displays a clear summary table for each semester

### How to Run
Compile with any C++ compiler and run:

```bash
g++ CodeAlpha_CGPA_Calculator.cpp -o app
./app
